# SkillPilot AI 2.0

## Project Description

SkillPilot AI 2.0 is an AI-powered Skill Gap Mapper and Placement Roadmap Generator.

The system analyzes a student's resume, compares it with industry job requirements, identifies missing skills, and generates a personalized learning roadmap.

---

## Problem Statement

Many students apply for jobs without knowing whether their skills match industry requirements.

Recruiters spend significant time reviewing resumes manually.

SkillPilot AI helps students understand their strengths, identify missing skills, and improve placement readiness.

---

## Objectives

- Resume Analysis
- Skill Extraction
- Role Matching
- Skill Gap Detection
- Learning Roadmap Generation
- Placement Readiness Assessment

## Installation

1. Clone Repository

```bash
git clone <repo-url>
```

2. Create Virtual Environment

```bash
python -m venv .venv
```

3. Activate Environment

```bash
.venv\Scripts\activate
```

4. Install Dependencies

```bash
pip install -r requirements.txt
```

5. Run Application

```bash
streamlit run app.py
```
